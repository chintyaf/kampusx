Konsep Stored Program Computer

Dalam arsitektur komputer modern, konsep Stored Program Computer menetapkan bahwa data dan instruksi disimpan bersama di dalam memori utama komputer[cite: 209]. Instruksi di dalam program akan dilaksanakan secara berurutan oleh pemroses (CPU)[cite: 209].

Proses pengolahan data mengikuti alur dasar: Input membawa data dan instruksi ke dalam sistem, Process mengolah data di dalam memori/penyimpanan (storage), dan Output menghasilkan informasi hasil pengolahan[cite: 209].

Pengertian Tipe Data (Type)

Tipe data (type) merupakan pola representasi data di dalam komputer yang berfungsi untuk mendefinisikan jenis objek yang diprogram[cite: 210]. Pendefinisian tipe data dilakukan dengan menentukan beberapa komponen utama[cite: 210]:

  • Nama Tipe: Menentukan nama tipe di dalam kamus definisi[cite: 210].
  • Domain Harga: Rentang nilai yang dapat ditampung oleh tipe data tersebut[cite: 210].
  • Konvensi Penulisan Konstanta: Aturan sintaksis penulisan nilai tetap[cite: 210].
  • Operator: Himpunan operasi matematika atau logika yang valid dilakukan terhadap tipe tersebut[cite: 210].

Klasifikasi Tipe Data

Secara umum, tipe data dibedakan menjadi dua jenis, yaitu tipe dasar dan tipe bentukan[cite: 210]. Tipe dasar adalah tipe data yang sudah didefinisikan secara langsung oleh pemroses bahasa[cite: 211]. Tipe data dasar meliputi[cite: 211]:

  • Bilangan logika (boolean)[cite: 211]
  • Bilangan bulat (integer)[cite: 211]
  • Bilangan real (float)[cite: 211]
  • Karakter[cite: 211]
