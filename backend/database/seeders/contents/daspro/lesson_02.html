1. Bilangan Logika (Boolean)

Tipe data boolean memiliki domain harga yang terdiri dari dua nilai: True dan False[cite: 212]. Operator logika utama yang berlaku meliputi and (dan), or (atau), dan not (negasi)[cite: 212].

2. Bilangan Bulat (Integer)

Tipe data integer menampung himpunan bilangan bulat tanpa desimal (contoh konstanta: 0, 16, -57, 1009)[cite: 214]. Tipe data ini mendukung operator aritmatika dan relasional[cite: 214, 215].

Operator Aritmatika Integer

Operator Arti Tipe Hasil Contoh Hasil

//Bagi integerInteger10 // 33
%Sisa bagiInteger10 % 31

Operator Relasional Integer

Operator relasional membandingkan dua nilai dan menghasilkan tipe data Boolean[cite: 215]:

  • < (Lebih Kecil), contoh: 2 < 5 → True[cite: 215]
  • <= (Lebih kecil sama dengan), contoh: 5 <= 7 → True
