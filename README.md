# 🎓 KampusX (Student Hub Space)

KampusX is a one-stop event management platform designed to connect students with self-development opportunities like seminars, workshops, and open classes. 

Built on a simple philosophy: **Fast for students, organized for committees, and secure for admins.**

## 🌟 Key Features by Role

**🎓 For Students (Participants)**
* **Smart Feed & Discovery:** Personalized event recommendations based on interests, with easy search and filter tools.
* **Seamless Ticketing:** Quick checkout with integrated payments (QRIS/E-Wallet) and a centralized "My Tickets" inventory.
* **Certificate Vault:** E-certificates are automatically generated, unlocked after submitting event feedback, and safely stored in a personal digital portfolio.

**📋 For Event Creators (Organizers)**
* **Centralized Dashboard:** Easily create events, manage ticket tiers (VIP, Regular), and target specific universities.
* **Streamlined Field Operations:** Real-time QR attendance scanning using station-based PINs (Kiosk Mode), ensuring fast check-ins without requiring individual staff logins.
* **Automated Workflows:** Auto-generate participant certificates, track attendance data, and export reports instantly.

**🛡️ For Admins (Moderators)**
* **System Integrity:** Verify event creators to prevent fraud, moderate content, and oversee secure payment flows.
* **User Management:** Handle account issues and maintain the overall security of the platform ecosystem.
