1. Arsitektur Stored Program Computer

Komputer bekerja berdasarkan prinsip Stored Program Computer, di mana data dan instruksi disimpan bersama di dalam memori. Instruksi di dalam program dilaksanakan secara berurutan (sekuensial).

Komponen Utama:

  • Input: Menerima data dan instruksi masukan dari pengguna.
  • Process & Storage: Mengolah data dalam CPU dan memproses instruksi di memori.
  • Output: Menampilkan hasil pemrosesan informasi ke piranti keluaran.
2. Pengertian & Klasifikasi Tipe Data

Type (Tipe Data) adalah pola representasi data dalam komputer yang mendefinisikan objek yang diprogram, domain nilai, konvensi konstanta, dan operator yang berlaku.

Tipe Data Dasar (Built-in)

  • Boolean: Logika (True / False)
  • Integer: Bilangan bulat (10, -5)
  • Float: Bilangan real (3.14, 0.5)
  • Karakter / String: Teks ('A', "Maranatha")

Tipe Data Bentukan

Tipe yang disusun pemrogram dari tipe dasar:

  • Array / List
  • Record / Struct / Class

Deklarasi Data Tipe Dasar 

            
                # File: ContohDeklarasiData.py
def main():
    Radius = 10                  # Integer
    LuasLingk = 22/7 * (10/2)**2 # Float
    Ketemu = True                # Boolean
    Nama = "Maranatha"           # String
    Gender = 'L'                 # String/Char

    print(Radius, LuasLingk, Ketemu, Nama, Gender)
    return 0

if __name__ == '__main__':
    main()
