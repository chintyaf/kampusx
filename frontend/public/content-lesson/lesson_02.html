1. Bilangan Logika (Boolean)

Tipe data Boolean hanya memiliki domain harga True dan False dengan operator utama and, or, dan not.

x y not x x and y x or y
True True False True True
True False False False True
False True True False True
False False True False False

2. Operator Relasional

Operator relasional membandingkan dua nilai dan menghasilkan keluaran bertipe Boolean:

  • < (Lebih kecil) → 2 < 5 (True)
  • <= (Lebih kecil sama dengan) → 5 <= 7 (True)
  • > (Lebih besar) → 2 > 2 (False)
  • >= (Lebih besar sama dengan) → 5 >= 5 (True)
  • == (Sama dengan) → 'a' == 'A' (False)
  • != (Tidak sama dengan) → 'a' != 'A' (True)

Kode Python Operasi Logika & Relasional 

x = True
y = False

print("not x   :", not x)     # False
print("x and y :", x and y)   # False
print("x or y  :", x or y)    # True

print("10 // 3 :", 10 // 3)   # 3 (Bagi Integer)
print("10 % 3  :", 10 % 3)    # 1 (Modulo)
print("'a' < 'c':", 'a' < 'c')  # True
