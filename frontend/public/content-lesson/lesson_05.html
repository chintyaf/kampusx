Aksi Sekuensial adalah struktur kendali di mana sederetan instruksi dieksekusi secara berurutan, baris demi baris dari atas ke bawah.

2. Algoritma Tukar Isi Variabel (Swapping)

Proses menukar nilai x dan y membutuhkan satu variabel bantuan (t):

  1. Simpan nilai x ke variabel sementara → t = x
  2. Isi x dengan nilai dari y → x = y
  3. Isi y dengan nilai awal x yang disimpan di t → y = t

Kode Python Program Tukar Isi Variabel (Tukar.py) 

# File: Tukar.py
def main():
    x = int(input("Nilai x :"))
    y = int(input("Nilai y :"))

    # Algoritma Tukar Nilai
    t = x
    x = y
    y = t

    print("Setelah tukar -> Nilai x:", x, "| Nilai y:", y)

if __name__ == '__main__':
    main()
