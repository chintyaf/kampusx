1. Aturan Penamaan Variabel (Identifier)

Penamaan variabel harus memenuhi batasan sintaks berikut:

✅ Contoh Nama BENAR

  • Harus dimulai dengan huruf atau _
  • Tanpa spasi dan tanpa karakter operator
  • Bukan nama kata kunci instruksi (reserved word)
  • Contoh: DataKe1, Data_1, totalNilai

❌ Contoh Nama SALAH

  • $Data (Karakter khusus di awal)
  • Data 1 (Mengandung spasi)
  • Data-1 (Mengandung operator minus -)
  • input (Reserved word instruksi)

2. Instruksi Assignment

Assignment adalah instruksi menyimpan nilai ke dalam variabel. Tipe data variabel harus bersesuaian dengan tipe data nilai yang disimpan.

<nama1> = <konstanta>
<nama1> = <nama2>
<nama1> = <ekspresi>

Kode Python Instruksi Assignment 

def main():
    nilaiA = 250        # Inisialisasi konstanta integer
    nilaiY = 20.5       # Inisialisasi konstanta float
    nilaiB = nilaiA     # Assignment dari variabel lain
    nilaiC = nilaiA + nilaiB # Assignment dari hasil ekspresi

    print("nilaiC:", nilaiC) # Output: 500

if __name__ == '__main__':
    main()
