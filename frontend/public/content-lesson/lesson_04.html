1. Perintah Input & Type Casting

Perintah input() membaca masukan dari pengguna sebagai teks (String). Gunakan fungsi int() atau float() untuk melakukan konversi tipe data (type casting).

2. Formatting Output (sep & end)

  • end: Menentukan karakter di akhir baris (default `\n`).
  • sep: Menentukan karakter pemisah antar argumen output.
  • Formatting Float: "{0:4.2f}".format(y) memformat float ke 2 digit angka desimal.

Kode Python Input, Output, & Formatting 

def main():
    nama = input("Ketikkan nama: ")
    nilaiC = int(input("Masukkan nilai C: "))

    # Penggunaan end dan sep
    print(5, end=" ")
    print(0.0025) # Dicetak di baris yang sama (5 0.0025)

    print("Hello from ", nama, "!", sep="")
    print("Formatted float: {0:4.2f}".format(0.25678)) # Output: 0.26

if __name__ == '__main__':
    main()
