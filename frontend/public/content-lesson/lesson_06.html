1. Spesifikasi Perhitungan Konversi Detik

Mengonversi total nilai detik $N$ menjadi Jam, Menit, dan sisa Detik menggunakan pembagian bulat (//) dan sisa bagi (%):

  • Jam = N // 3600
  • Sisa = N % 3600
  • Menit = Sisa // 60
  • Detik = Sisa % 60

2. Tracing Nilai (Contoh Input: 5000 Detik)

  • Jam = 5000 // 3600 = 1 Jam
  • Sisa = 5000 % 3600 = 1400 detik
  • Menit = 1400 // 60 = 23 Menit
  • Detik = 1400 % 60 = 20 Detik

Kode Python Program Konversi Detik (KonversiDetik.py) 

# File: KonversiDetik.py
def main():
    Detik = int(input("Input Detik: "))

    J = Detik // 3600
    Sisa = Detik % 3600
    M = Sisa // 60
    D = Sisa % 60

    print("Hasil Konversi:", Detik, "detik")
    print("Jam   :", J)
    print("Menit :", M)
    print("Detik :", D)

if __name__ == '__main__':
    main()
